# Agentic Development Template

A minimal, language-neutral starting point for projects developed with human and AI collaborators.

Use this repository as a GitHub template or import its root files into a new project. It establishes only the shared working conventions that are useful before a project has chosen a language, framework, deployment target, or automation approach.

## Included

- `AGENTS.md` — default guidance for human and AI contributors.
- `.editorconfig` — portable whitespace and line-ending conventions.
- `.gitattributes` — consistent text handling across platforms.
- `.gitignore` — local, operating-system, editor, secret, and agent-state exclusions.

## Starting a project

1. Create a repository from this template in GitHub, or copy these root files into an existing repository.
2. Define the project's purpose, technology choices, and repository layout.
3. Add project-specific tooling, automation, documentation, and contributor guidance only when those choices are known.

To make this repository available through GitHub's template picker, enable **Template repository** in its GitHub repository settings after publishing it.

## Intentional boundaries

This template does not prescribe a language, package manager, source layout, test framework, CI workflow, licence, issue process, or deployment model. Those decisions belong to each project that uses the template.
