# Contributor Guidance

These defaults apply until a project adds more specific instructions.

## Working principles

- Inspect the repository and its existing conventions before making changes.
- Keep changes narrowly scoped to the requested outcome; do not perform unrelated cleanup or refactoring.
- Follow the project's established tooling, patterns, and documentation once they exist.
- Validate changes with the relevant checks available in the repository, proportionate to the change and its risk.
- Preserve existing user work. Do not overwrite, discard, or revert unrelated changes.
- Ask for direction before destructive, high-impact, irreversible, or materially ambiguous actions.

## Project-specific instructions

When a project introduces more specific guidance, place it in this file or in clearly referenced documentation. More specific, applicable instructions take precedence over these defaults.
